📖 About

This is a single-page portfolio built with pure HTML5 and CSS3 (no frameworks or JavaScript). It presents an introduction, a skills overview, a showcase of real projects, and a contact form, all wrapped in a clean, dark-themed, developer-focused design.

✨ Features
Fully responsive layout (desktop, tablet, mobile) using a single media query breakpoint
Sticky navigation header
Dark navy theme with cyan/amber accent colors, defined through CSS custom properties (:root variables) for easy theming
Reusable card components for skills and projects
Hover animations (lift + glow effects) on cards, buttons, and links
Semantic HTML structure with anchor-linked navigation (#skills, #projects, #contact)
Google Fonts pairing: JetBrains Mono (headings/monospace accents) + Inter (body text)
🛠️ Built With
HTML5 — semantic markup
CSS3 — Flexbox, custom properties, transitions, media queries
Google Fonts — JetBrains Mono, Inter

No build tools, frameworks, or dependencies — just plain HTML and CSS.
